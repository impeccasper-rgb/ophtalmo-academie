1. **m-oct-6 = OPH-191 est SANS licence CC** (tutoriel POAG, © Univ. of Iowa) : à ne pas utiliser dans une démo marketing publique sans permission écrite. Remplaçant CC possible pour le même piège de couleur : OPH-132 (OD : S 61, I 52, T 39 rouges ; N 50 vert) — l’énoncé changerait (« le nasal 50 µm est vert »).
