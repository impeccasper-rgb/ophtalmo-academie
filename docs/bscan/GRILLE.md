# Échographie B — grille d’extraction remplie

Même grille pour toutes les sources. Identifiants : voir `CORPUS.md` (V = vidéo avec minutage, W = écrit). « — » : la source n’en parle pas. Les minutages viennent des transcriptions automatiques (± quelques secondes).

Abréviations : NO = nerf optique ; DR = décollement de rétine ; DPV = décollement postérieur du vitré ; DC = décollement choroïdien ; HV = hémorragie du vitré ; CEIO = corps étranger intraoculaire.
